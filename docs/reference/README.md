# Reference screenshots

The owner can put screenshots here to compare against (for example Apple Music screens on iPhone, iPad and Mac, and Material 3 Expressive examples). Name them by screen, such as `now-playing-ios.png` and `lyrics.png`.

Rules: these are for private comparison while building. Do not ship them, do not copy another app's artwork, icons or text into the app, and do not commit anything the owner does not have the right to keep in the repo. If this repo is public, add this folder to `.gitignore` first.
