Platform design languages

Every platform has the same structure, copy, gestures and behavior. What differs is the material. iPhone, iPad and Mac get Liquid Glass: light, translucent surfaces that float over the album. Android gets Material 3 Expressive: tonal color, big shapes, and springy motion that you can read from the shape of a control. Windows and Linux get the same Expressive look, built as a small Flutter theme and drawn at desktop density.

MaterialGlass is for things that float over content: the tab bar, mini player, buttons over artwork, menus and sheets. Lists and page backgrounds stay plain, and glass is never stacked on glass.
ShapeCapsules for buttons and bars. Where one shape sits inside another, the radii are concentric (inner = outer minus padding) so corners run parallel. Album art takes one radius, 14 pt, on all four corners, even inside a capsule.
ColorThe content supplies the color. The album gradient sits behind the glass and shows through it. Selection uses the system tint. Text over light art flips to dark.
MotionSprings only. Glass lifts and shimmers under the finger, menus morph out of the pressed item, and the tab bar shrinks while scrolling down.
TypeLarge bold titles that collapse into the bar, tight tracking, one clear step between title and subtitle.
Built withSwiftUI glassEffect, GlassEffectContainer, tabBarMinimizeBehavior and MeshGradient. Earlier iOS versions fall back to the system blur materials. iPad and Mac use the same components; the Mac adds a menu bar, hover and a floating sidebar.

ColorTonal surfaces from dynamic color: primary, secondary and tertiary containers, with a scheme built from the playing album. Color carries hierarchy, so shadows stay rare.
ShapeLarge radii (28 dp on art and cards) and a shape set for generated content: cookie, sunny, clover, arch, squircle, pill. Real album art never takes these; it keeps one plain radius on all four corners.
Button groupsOuter corners fully round, facing corners 10 dp. The selected item becomes fully round, so the choice reads from shape alone, and pressing morphs a button while its neighbors squeeze.
MotionExpressive springs. Wavy progress with a pill handle, a loading indicator that turns and morphs between shapes, and a navigation pill that slides under the chosen tab.
TypeEmphasized styles: bigger, heavier titles (34 sp, weight 500 to 600) and compact body text.
Built withJetpack Compose Material 3 expressive APIs: MotionScheme.expressive(), ButtonGroup, MaterialShapes, LoadingIndicator and the wavy progress indicators.

Windows and Linux · Material 3 Expressive, desktop density

LookThe Android language at desktop density: tonal surfaces, 28 px pane corners, connected button groups, wavy progress, spring motion. The same Play, Shuffle and Add group, hover and focus states, a table for songs, and the system caption buttons.
Why not Liquid GlassGlass is Apple's material. Windows and Linux windows sit over arbitrary desktops, so a tonal, opaque surface reads reliably everywhere and stays close to Android, as requested.
Built withFlutter with a small Encore theme: color roles from the album, shape tokens, connected button groups and a wavy progress painter, because Flutter does not ship the Expressive components. Optional Mica backdrop on Windows 11.
Shared on all platforms. Screen structure, wording, gestures and what each haptic means, accessibility behavior, and the album-driven color. A change to behavior is made once and lands everywhere.
