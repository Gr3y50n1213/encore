Encore · mock-up 48 · Phase 12 stage 2

Signing in to Plex

Plex accounts sign in through plex.tv, not with a username and password typed into Encore. This changes only the Connect step of board 21. Everything after it (Choose what to include, Optional sync) stays the same. Android is shown. iOS follows the same steps in its own style.

Behaviour

  1. Server type. The group becomes Jellyfin, Emby, Navidrome, Plex. Emby and Navidrome use the normal address, username and password form. Emby has no Quick Connect.
  2. Sign in with Plex. Asks plex.tv for a 4-character code. The spinner sits in the button while it loads. With no internet the message says so plainly.
  3. The code. Valid for 15 minutes, with a countdown. Copy code gives a short confirmation. Cancel and Back return to step 1. Coming back from the browser resumes the wait. Encore checks plex.tv every few seconds and stops when the code expires or the screen closes.
  4. What is kept. Only the chosen server's access token, in the system keystore, and never the Plex password. The account-wide token is thrown away once the server is chosen.
  5. Addresses. Encore prefers a secure address on the same network, then a secure internet address. If the server moves, Encore asks plex.tv for its new address, and that is the only other time it contacts plex.tv.
  6. Errors. No servers on the account: "This Plex account has no servers yet". None reachable: shows each server dimmed with "Not reachable right now" and a Try again button.
