Permissions and system prompts
1
Primer first. Before any system prompt, the app shows one short screen in its own words: what it will ask, why, and that denying costs only one feature. It appears in context, at the moment the feature is used, never at launch and never as a stack of prompts. TAPContinue shows the system prompt. HAPTICsoft.
2
System prompt. Drawn by the OS and not editable; only its purpose string comes from the app (iOS) or the permission name (Android). Dashed outline here marks what the OS owns. The text must say what the app really does, and each string is reviewed against the plan's network list.
3
Not now. Closes the primer with no system prompt, so the one-time OS prompt is saved for later. The feature shows a quiet "Turn on" row where it would have worked. GUARDno feature is blocked behind a permission, and the app never asks twice in one session.
