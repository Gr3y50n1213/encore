Widgets and media surfaces on Android, Windows and Linux

Android gets the same four widgets as Apple devices, in Material 3 Expressive. Windows 11 gets Adaptive Card widgets, a taskbar that shows progress, and system media controls. Linux gets MPRIS, notifications and dock actions, and no desktop widgets in version 1. Everything reads a local snapshot or the media session, and nothing is pushed. Dashed outlines mark what the system draws.

1
Android widget set. The same four widgets as on Apple devices, built with Jetpack Glance and Material 3 Expressive: Now Playing, Mixes, Recently played and Recap. Each is resizable between its minimum and maximum cell sizes, from 2×1 up to the sizes shown. The widget background uses the system corner radius, and inner shapes use the system inner radius, so it matches the launcher. Colors follow the wallpaper (dynamic color, light and dark). Previews in the picker are generated from the demo library, never the person's own history.
2
Now Playing (Android). Cover, title, artist, previous, play or pause, and next. The buttons go to the playback service as media session actions and never open the app. The progress bar is drawn from the last update and refreshed on every track or state change; a widget cannot animate and the system limits how often it may update, so the bar is an indicator, not a clock, and the 2×1 size leaves it out. Tapping the cover or text opens Now Playing.
3
Mixes, Recently played and Recap. A tap on a mix tile starts it in the background through the playback service; a tap on a recent cover opens the album page. The widget is configured when it is placed: Profile, and for Mixes a pinned mix or Next up. Recap shows the top artist and minutes so far and says Your recap builds as you listen until there is enough data. Touch targets are at least 48 dp; the play button sits inside the tile so a stray tap near the edge opens the page instead of playing.
4
Quick Settings tile and lock screen. The Start a mix tile has three states: inactive (the mix name), active (Playing) and unavailable (Unlock Encore, when the profile has a PIN and the phone is locked). Tap starts the pinned mix; touch and hold opens the mix in the app. On phones from Android 16 QPR1 and on the Pixel Tablet, Now Playing is the only Encore widget offered on the lock screen; the widgets that show history declare not_keyguard so they cannot be placed there. States are always words, with no error icon.
5
Windows Widgets board. Windows 11 only. A packaged build (MSIX, or with package identity) registers a small widget provider, a Rust component beside the Flutter app, that runs out of process and is started by Windows when a widget is added; an unpackaged portable build has no widgets. Widgets are Adaptive Cards in small, medium and large, drawn in the Windows style with Windows buttons and colors, so Encore supplies the data and the layout and not the pixels. Customize widget (from the ⋯ menu) holds Profile and Mix, the same two settings as everywhere else. A new widget with no history shows Nothing yet and one button. There is no Recap widget on Windows. Windows 10 has no widgets board.
6
Windows taskbar, Jump List and toast. The taskbar button shows green progress for a download the person started and a moon badge while the sleep timer runs; both are removed when the task ends. Hovering shows the thumbnail with previous, play or pause and next. The Jump List has only Mixes and Tasks, and the system Recent list is turned off for Encore so it never records what was played. A progress toast covers downloads and the first sync; it updates in place, makes no sound and has Cancel. A small native Windows plugin connects these to the Flutter app.
7
Windows media controls. The system media flyout, the quick settings media card, the lock screen and headset keys all come from the System Media Transport Controls. The app sets the title, artist, album, cover, position and the enabled buttons when the track or state changes and the system does the rest, so nothing runs while the screen is locked. Windows shows no third-party widgets on the lock screen, so this is the whole lock screen story.
8
Linux media controls. Encore publishes MPRIS 2 on the session bus, from the Rust core, with title, artist, album, artwork, length, position and the enabled commands. GNOME draws it in Quick Settings and on the lock screen, Plasma in the tray media controller and on the lock screen, and headset and keyboard keys use it as well. Artwork is written to a private cache file, replaced on every track and removed on quit, because the shell reads it by path.
9
Linux notifications, dock and tray. A download the person started gets one freedesktop notification with a progress value, updated in place; desktops that ignore the value show the words only. The launcher entry reports progress and a count, shown by Plasma, Ubuntu's dock and Dash to Dock where they support it. The .desktop file has Desktop Actions (Play or pause, Next song, Start a mix) so every desktop gets them in the right-click menu. A tray icon through StatusNotifier is optional, because GNOME needs an extension for it, and nothing depends on it. When it is there, the sleep timer shows as its tooltip. There are no desktop widgets in version 1: Plasma plasmoids and GNOME extensions are not stable enough to promise.
10
Data, privacy and refresh. On Windows the core writes the same per-profile snapshot to the app's local data folder, and the widget provider reads that file and nothing else: never the database, never the network. On Android it is a Glance state the core fills. Each widget has a Profile setting, Active profile by default; a profile with a PIN and the guest profile show the neutral Open Encore card. Updates are made by the running app, never by push: no FCM token, no WNS channel, no server-side widget refresh. A widget that has not updated for 24 hours dims and says Open Encore to refresh.
Not drawn. Windows 10 and Windows live tiles (removed by Microsoft), KDE Plasma plasmoids, GNOME extensions, ChromeOS and Wear OS. To verify while building. The Windows widget provider from a Flutter app (it needs package identity), the Android 16 lock screen widget category on a real phone, and whether the Linux dock shows the launcher entry progress on the target desktops.
